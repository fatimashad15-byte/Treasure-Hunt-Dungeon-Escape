\# Programming Fundamentals CCA Project



### **Treaure Hunt: Dungeon Escape**



##### **## Project Description**

This project is developed using the C programming language as part of the Programming Fundamentals course (CT-175).

Dungeon Escape is a console-based maze adventure game developed using the C programming language as a Programming Fundamentals project. In this game, players explore a dungeon, collect hidden treasures, avoid dangerous traps, and find the exit to complete each level.

##### **## Features**



1\. Three Difficulty Levels: Offers Easy, Medium, and Hard levels for different challenges.



2\. Two Game Modes: Includes Normal Mode and Torch Mode.



3\. Maze Exploration: Allows players to explore a dungeon using movement controls.



4\. Treasure Collection: Players must find and collect all hidden treasures.



5\. Trap System: Players must avoid traps to protect their lives.



6\. Limited Lives: Each player gets three lives to complete the game.



7\. Exit Challenge: Players must collect all treasures before reaching the exit.



8\. Torch Mode: Provides limited visibility and awards double points.



9\. Hint System: Players can use hints, but each hint costs three moves.



10\. Scoring System: Calculates scores based on the player's performance.



11\. Player Ranking: Assigns ranks according to the final score.



12\. Leaderboard: Displays saved player scores and records.



13\. Player Search: Allows users to search for a player's record by name.



14\. File Handling: Saves and loads player scores using a `scores.txt` file.



15\. Quit Option: Allows players to quit the game whenever they want.



##### **## How to Compile and Run**

1\. Open the project folder.

2\. Compile using: gcc main.c -o project

3\. Run using: ./project
